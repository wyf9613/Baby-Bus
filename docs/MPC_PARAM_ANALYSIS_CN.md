## 2. 有实车数据的几项细表

### 2.1 转向增益（5 号车，10-19）

包：`…-a5da-run1-184516`（模型 18°）、`…-ea03-run1-191128`（模型 21°，`ea0304c`）。实测满舵 23–25°，左右对称。

| | a5da（18°） | ea03（21°） |
| --- | --- | --- |
| 满舵占跟踪时间 | 28% | 12% |
| 1 s 内左右满舵来回 | 14 次 | 2 次 |
| 跟 lattice 时航向误差 p95 | 0.81 rad | 0.25 rad |
| 跟 lattice 时横向误差中位数 / p95 | 2 / 13 cm | 1.5 / 10.6 cm |
| 最高车速 | 0.47（超速锁停 2 次） | 0.358（无超速） |
| 控制层停车 | 超速 2 次 | 0 |

局限：两次之间还改了别的项（油门上限按原始轮速判断、`drive_max` 0.38），超速的改善不能全归到转向增益。

### 2.2 油门死区（5 号车）

| 时间 / 包 | 模型死区 | 结果 |
| --- | --- | --- |
| 10-15 17:53 `car05-v2-startfix-exec-…175338` | 0.289 | 交接后车速 0.18 → 0.06，偏置用约 3 s 才拉回 0.106 |
| 10-15 18:18 `car05-v2-db032-exec-…181825` | 0.32 | 两次都在约 0.20 m/s 超速停车，模型预测约 0.12 |
| 10-19 现场 `car05-lattice21-20261019-161732-197` | 0.30 | 满电时 0.25 的请求就维持约 0.255 m/s，MPC 以为在滑行，偏置顶到 -0.05，超速锁停 |
| 10-19 晚 b93d、a5da、ea03 | 0.24 → 0.25 | 偏置 ±0.10 覆盖电量变化；ea03 控制层停车 0 |

结论：联合 MPC 的纵向对死区很敏感，差 0.03 就从"减速"变成"超速"，而且死区还随电量漂移。这也是组内对比要回答的问题：模型不准时，纵向是否应该交给反馈。

## 3. 实车补测计划

一次上车按优先级排，每次只改一个参数，包从基础包复制后只改一行，记下 yaml 哈希，用 `ros2 param get` 核对。

| 顺序 | 对比 | 包 | 场景 | 次数 |
| --- | --- | --- | --- | --- |
| 1 | `joint` / `feedback` | `v020-nolimit` / `v020-nolimit-fb` | 整条赛道 | 各 3–5，交替 |
| 2 | `r_ddelta` 2 / 5 | `v020-nolimit` / `v020-nolimit-rd5` | 整条赛道 | 各 3–5，交替 |
| 3 | `off` / `hooks` | `v020-nolimit` / `v020-nolimit-hooks` | 急右弯 | 各 3–5，交替 |

所有包都用 `tools/car_run_metrics.py` 统计：横向看满舵占比、左右反打、越界次数；纵向看切油门的时间占比、超过 0.30 / 0.40 的秒数、重新起步次数。估计层停车单独列。

## 4. 报告里怎么写

每个参数一段：改了什么 → 对应哪个物理量 → Gym 结果 → 实车结果 → 结论和局限。"前后"证据要写明不是 A/B。
