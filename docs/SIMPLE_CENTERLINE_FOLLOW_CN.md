# 最简恒速中心线 policy

分支：`fix/newcar-control`。运行链路：

**相机锥桶 + 轮速/gyro → 二维有序边界 → 法线配对中线 → 弧长预瞄 PID → 动作。**

当前工作区为急弯控制改进候选，实车效果待验证。缓弯实测基线已 push 为 `271bfb9`，
包含旧 `y(x)` 道路和末段直行 0.8 m。当前配置选择 `ordered_xy`，关闭自动末段直行。

单一 20 Hz timer 同步完成上述步骤。没有 lattice、候选搜索、规划 worker、
重新生成回正轨迹或三帧启动确认。中心线会随新的感知和运动补偿更新，
不是启动时冻结一条道路；车辆偏离后，纠正动作由控制器计算。

## 感知与规划

在原 road-estimation-v2 基础上增加 `estimation.road_geometry=ordered_xy`。
旧 `y_of_x` 拟合模式保留。连续移动真实锥桶历史、合并部分新观测、短时道路预测
由感知完成。原始采集时间和历史点年龄保留，预测不刷新来源年龄。

`planning.algorithm: road_centerline` 原样使用 `road.centerline_xy`，不拟合成
直线，也不因偏移、航向或曲率生成另一条路径。当前编码为 `ORDERED_CENTERLINE`，
至多 201 个按行驶顺序排列的 `[x,y]` 点，独立变量为弧长 `s_m`。
竖直路段与 x 递减的 U 弯出口不再因斜率或 x 点序被拒绝。

锥桶链从车旁支持出发，结合相邻距离和方向连续性向前/后生长。
连接间隔同时受配置绝对上限与局部锥桶间距限制，避免 U 弯末端跨空隙接回入口。
双侧用局部法线与另一侧同向路段相交配对，匹配沿另一侧弧长前进；
不把 U 弯入口与反向出口直接求平均。只保留连续、足够长的配对支持。
中心线先作一次有界局部平滑，再按自己的弧长重采样。
这是局部几何近似，未加入标定转弯半径或车身扫掠约束。

若感知返回 `near_field_unobserved`，且 `forward_geometry` 的几何和时间对齐
有效，允许只用已观测前方中心线。没有向后补画边界，也没有证明车旁车身净空。
只检查当前输入、坐标/时间、有限值、点序和间隔；没有全车身碰撞/障碍规划。

`estimation.single_side_from_learned_width=true` 启用当前跑次内的宽度记忆：
只从新鲜原始双侧有效观测学习完整宽度 W，缺一侧时沿可见边界的局部法线向内偏移
`single_side_offset_fraction * W`（当前为 0.6W；0.5W 恢复中点），
用每帧新单侧观测更新轨迹；旧另一侧锥桶历史不再否决此轨迹。
远侧锥桶回来但双侧共同范围不足时，继续使用有效边界和记住的宽度比例。
双侧具备足够共同范围且有效时更新宽度、
恢复双侧中线。记住的宽度在单侧期间固定，不会被单侧/合并历史/预测重新学习。
该轨迹保留单侧来源标记，MVP planner 显式接纳；缺失边界不会标记成真实观测。
单侧阶段假设局部道路宽度不变；停止/重启/运动重置后须重新获得双侧宽度。

按用户最后要求，**所有可用道路的目标速度恒定为 0.2 m/s**，包括弯道和
仍在期限内的预测道路；不消费感知的减速建议。
预测用尽、其他道路无效、反馈失联、
操作员停止时仍归零。2026-10-14 按用户要求将 `control.max_distance_m` 和
`max_run_time_s` 设为 0，关闭 3 m/30 s 测试预算；正数可恢复对应预算。

相机源年龄预算在感知与 planning 两侧统一为 1.5 s。轮速/gyro 各自仍最多
0.25 s；参考最多 0.2 s，并受所有输入的剩余期限以及预测剩余时间约束。
短时预测最多 0.8 s、累计行驶最多 0.5 m，任一约束可更早结束预测。
新鲜单侧偏移轨迹按当前相机帧的新鲜度检查，不使用旧路径预测预算。
ordered_xy 还保留新鲜单侧真实锥桶链，因此单侧跟踪后的短暂双侧缺桶可继续预测该曲线。
缺失侧始终标记为半宽推断；原采集时间和宽度学习时间不刷新。
相机/运动失效、预算用尽或几何矛盾仍停车，并要求显式恢复。
当前 `control.end_straight_distance_m=0.0`：几何不足不会自动改为直行。

## 可选旧末段直行 0.8 m（当前关闭）

`control.end_straight_distance_m=0.80` 启用补丁：本轮成功跟踪后遇到上述几何不足，
保持状态 3，直接输出固定油门 `end_straight_drive_normalized=0.30` 和转向 0，
从触发时的轮速积分开始补走 0.80 m，然后进入连续零动作状态 2。此段不使用
相机轨迹或速度 PID，也不消费旧参考；绿线清空。锥桶返回也不再恢复跟踪或重置距离。
再次运行须显式请求状态 3，重置本轮模式与半宽记忆。

相机消息仍须新鲜，允许新鲜空帧；轮速和 gyro 继续满足各自原运动新鲜度要求。
独立 supervision 负责距离截止，油门固定时轮速持续为零也在 `end_straight_max_time_s=8.0`
到期归零。手动 Stop、源断流、运动/时钟间隔异常、已有正数距离/时间预算仍可提前停止。
将距离设为 0.0 恢复原先几何不足立即停车。归一化转向 0 要配合车辆实时 trim=0。

这个触发条件不能区分终点与弯道掉桶，用户已选择自动按几何不足触发；此后直行并停车。
0.80 m 是轮速积分目标，实际位移仍受标定、打滑和滑行影响。
补丁的 0.30 m 和 1.0 m 配置已通过 pinned Jazzy 完整 gate：258 项，零失败/错误/跳过；portable 171。
检查包括完成后锁存停车、仅一次触发、数据失效、手动停止、返桶和真实 PolicyNode 清线。
两档实测均按末段距离达到停车，1 m 补偿阶段约 4.64 s；用户最终选择 0.8 m。
最终值已构建、重启策略并读回确认，按用户要求不再追加检查/试跑。最终策略 2 / Disabled。
完整证据见 [末段补偿记录](experiments/2026-10-14/CAR15_END_STRAIGHT_REPORT_CN.md)。

## 控制

横向控制取中线上最近线段的法向误差，以及最近位置前方 0.35 m 的道路切线
方向；0.35 m 沿道路弧长计算，使用 `atan2` 保留转弯方向和完整角度。
最近路段选择排除相对当前车头反向的出口，避免跳过 U 弯。
预瞄不足时只使用最近的实际支持端点，不外推中线。前方观测尚未覆盖
车体时，当前 `mvp_ordered_cornering_enabled=true` 将预瞄点 y 与局部法向误差、
朝向预瞄点的方位角与预瞄切线分别连续混合。局部/切线权重为
`preview / (preview + entry_distance)`；最近投影在路段内部时 entry_distance 为 0，
只看到远处入口时取入口沿切线方向到车辆的非负距离。道路接近车体时连续增加
局部/切线权重，让弯道方向提前参与反馈，并消除端点模式切换造成的误差跳变。
原始最近线段误差仍记录到 debug1，Tracking 日志记录实际控制误差、权重和方向。
关闭该开关可恢复原来的端点/内部两种误差计算。

继续使用 main 的归一化横向 PI + 航向 P，车速使用原速度 PI + 前馈。
新增 0.10 s 当前横向/航向误差低通，航向沿最短角度方向平滑，缓和单/双侧切换。
这不会缓存失效参考；操作员 Stop 和无效输入直接归零并清除滤波状态。
不因每次中线更新重置控制积分。恒定 0.2 m/s 是目标速度，油门由反馈计算，
不是恒定油门，也不保证实际轮速恰好 0.2。

支持目标新增相邻锥桶足够密、行驶分支明确的直角与 U 弯。
分叉、稀疏锥桶造成的拓扑歧义、长期无道路和真实车身净空未验证。
合成几何、PID 模型及 ROS 检查不表示已确认实车转弯能力。
