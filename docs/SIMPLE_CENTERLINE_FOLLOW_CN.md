# 最简恒速中心线 policy

分支：`fix/newcar-control`。运行链路：

**相机锥桶 + 轮速/gyro → 新道路估计 → 原中心线采样 → PID → 动作。**

单一 20 Hz timer 同步完成上述步骤。没有 lattice、候选搜索、规划 worker、
重新生成回正轨迹或三帧启动确认。中心线会随新的感知和运动补偿更新，
不是启动时冻结一条道路；车辆偏离后，纠正动作由控制器计算。

## 感知与规划

只引入 `feature/road-estimation-v2@6552033` 的估计类和鲁棒拟合器，保留
main 的框架与控制器。连续移动真实锥桶历史、合并部分新观测、短时道路预测
由感知完成。原始采集时间和历史点年龄保留，预测不刷新来源年龄。

`planning.algorithm: road_centerline` 原样使用 `road.centerline_xy`，不拟合成
直线，也不因偏移、航向或曲率生成另一条路径。内部编码是
`CARTESIAN_CENTERLINE`，包含至多 201 个按 x 递增的 `[x,y]` 点及真实支持范围。

若感知返回 `near_field_unobserved`，且 `forward_geometry` 的几何和时间对齐
有效，允许只用已观测前方中心线。没有向后补画边界，也没有证明车旁车身净空。
只检查当前输入、坐标/时间、有限值、点序和间隔；没有全车身碰撞/障碍规划。

`estimation.single_side_from_learned_width=true` 启用当前跑次内的半宽记忆：
只从新鲜原始双侧有效观测学习宽度，缺一侧时沿可见边界的局部法线向内偏移半宽，
用每帧新单侧观测更新轨迹；旧另一侧锥桶历史不再否决此轨迹。
远侧锥桶回来但双侧共同范围不足时，继续使用近处有效边界和记住的半宽。
双侧具备足够共同范围且有效时更新宽度、
恢复双侧中线。半宽在单侧期间固定，不会被单侧/合并历史/预测重新学习。
该轨迹保留单侧来源标记，MVP planner 显式接纳；缺失边界不会标记成真实观测。
单侧阶段假设局部道路宽度不变；停止/重启/运动重置后须重新获得双侧宽度。

按用户最后要求，**所有可用道路的目标速度恒定为 0.2 m/s**，包括弯道和
仍在期限内的预测道路；不消费感知的减速建议。预测用尽、道路无效、反馈失联、
操作员停止时仍归零。2026-10-14 按用户要求将 `control.max_distance_m` 和
`max_run_time_s` 设为 0，关闭 3 m/30 s 测试预算；正数可恢复对应预算。

相机源年龄预算在感知与 planning 两侧统一为 1.5 s。轮速/gyro 各自仍最多
0.25 s；参考最多 0.2 s，并受所有输入的剩余期限以及预测剩余时间约束。
短时预测最多 0.8 s、累计行驶最多 0.5 m，任一约束可更早结束预测。
新鲜单侧偏移轨迹按当前相机帧的新鲜度检查，不使用旧路径预测预算。
两侧都无法拟合时，本版本停止。

## 控制

横向控制取中线上最近线段的法向误差，以及最近位置前方 0.35 m 的道路切线
方向；预瞄不足时只使用最近的实际支持端点，不外推中线。前方观测尚未覆盖
车体时，使用实际预瞄点的 y 和朝向该点的方位角，避免把远端切线法向距离
当作车旁横向误差。原始最近线段误差仍记录到 debug1，Tracking 日志另记
实际控制误差和采用的计算方式。

继续使用 main 的归一化横向 PI + 航向 P，车速使用原速度 PI + 前馈。
不因每次中线更新重置控制积分。恒定 0.2 m/s 是目标速度，油门由反馈计算，
不是恒定油门，也不保证实际轮速恰好 0.2。

当前候选参数：

| 参数 | 值 |
| --- | ---: |
| 目标速度 | 0.2 m/s |
| 速度 Kp / Ki | 0.35 / 0.08 |
| 油门前馈 / 上限 | 0.30 / 0.35 |
| 横向 Kp / Ki | 2.5 / 0 |
| 航向 Kp | 1.0 |
| 转向方向 / 策略上限 | -1 / 1.0 |
| 普通转向变化率 | 2.0 归一化单位/s；停止直接归零 |
| 车辆接口转向区间 | ±0.8；不是实测前轮角 |
| 实时转向 trim 基准 | 0.0；核对实时 topic，不能只查询启动参数 |
| 感知前向拟合窗口 | 4.0 m |
| 估计道路宽度范围 | 0.15–2.5 m；已部署 |
| 边界斜率上限 / Huber 容差 | 3 / 0.20 m |
| 单侧轨迹 | 记住上次双侧估计半宽；本轮偏移约 0.447/0.438 m |
| 首次历史中性等待上限 | 1.0 s；路径可用即执行 |

感知已有历史/预测，因此 `control.robustness_enabled=false`，不再叠加旧的
直线路径缓存。代码中保留的 V1 和旧缓存仅供显式选择历史方案，未走入当前链路。

支持目标是局部向前、能表示为 y(x) 的直道和普通弯道。回头弯、分叉、
长期无道路以及真实车身净空不属于本版已验证能力。

## 验证状态

运行到 4.543 m，首次增益/前方误差修复运行到 5.042 m，均因参考过期停止。
用户仍报告偏离中心线和修正不顺，跟踪尚未验收。

扩大转向至 ±0.8 并增加平滑后的唯一试跑，活动约 0.189 s、零里程，因
`invalid_width_or_order` 停止。离线重放确认：4 m 前向拟合在 21 帧中有 8 帧
远端宽度无效；3 m 的 21 帧均有效。真实停止前一帧的最小估计宽度分别为
0.259 m / 0.811 m，原有宽度保护为 0.3–2.5 m。
用户随后要求直接放宽门限；当前选用 4 m 窗口、0.15 m 宽度下限，替代未部署的
3 m 方案。0.2 m 下限仍会拒绝 2 帧，0.15 m 让 21 帧全部通过。
同一真实样本已通过实际 policy 方法回归：旧门限拒绝并归零，缩短范围和
放宽宽度两种方案均允许前方参考和驱动。每帧继续更新中线，反馈失联/数据过期
停止及显式恢复保留。当前检查与部署状态见 [验收记录](acceptance.md)。
