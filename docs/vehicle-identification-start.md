## 控制接口

- 单位：m、s、rad；车体 x 向前、y 向左，转向角左正。
- 转向：`delta = -0.3142 * steering_action`；正请求右转。左右前轮角到自行车等效角仍需独立复核。
- 前向非零请求暂用 `[0.3, 0.7]`；必须另行允许 `drive_action = 0.0`，不能把停车指令夹到 0.3。
- 起步与维持分开处理：遥控实测起步阈值约 `0.35`，运动后请求约 `0.3` 可维持低速。尚未保存该测试的时间序列，也未确认最低可维持请求；策略控制需复核遥控与策略输入映射，`drive_min=0.3` 不保证起步。
- 驱动请求表示电机作用量，不能直接赋值为目标速度。0.4 模型不能外推为完整请求—速度映射。
- `speed_limit_mps = 3.0` 是测试中止阈值。0.7 的 1 s 峰值低于该值，持续运行是否低于该值尚未验证。
- 参数未自动接入策略；控制器接入前与 Yiming / Zhenyu 对齐速度参考点、符号及 MPC 动力学方程。
