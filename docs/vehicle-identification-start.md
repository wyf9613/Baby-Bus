# Zhengxi Chen：实车参数测试

## 目标与范围

先完成必要参数的实车测量、辨识和复测，再交给 MPC / PID 使用，不等待控制器程序完成，也不以仿真辨识为前置条件。

当前 [vehicle_params.py](../offline/vehicle_identification/vehicle_params.py) 包含 16 项：车辆几何与外廓、转向映射与限制、驱动范围与响应、制动行为、转向与驱动延迟。未测值保持 `None`，仿真值仅作参考。

MPC 使用动力学自行车模型，仍需根据其具体方程确认是否缺少必要参数；与两组统一单位、符号、速度参考点及输入定义。测试方法和交付要求见 [实车测试计划](vehicle-params-test-plan.md)。

实机测试代码与命令见 [运行说明](../offline/vehicle_identification/README.md)。默认测试关闭，需完成 ROS 验证及现场配置后运行。
