# VehicleParams 实车测试计划 v0.1

## 测试方法

在确认车辆配置、ESC 制动/倒车规则及停止方式后，按下表由静态测量到低速动态测试开展。每个工况建议重复至少 3 次，并保留独立运行复测。

| 参数 | 测试方法 |
| --- | --- |
| `wheelbase_m` | 正常载荷、前轮回正，测前后轴中心的纵向间距，左右两侧重复测量。 |
| `rear_axle_from_cg_m` | 前后轴在同一水平高度分别称重；用轴距 L、前轴读数 F、后轴读数 R 计算 `l_r = L*F/(F+R)`，F、R 使用同一单位。 |
| `body_front_extent_from_cg_m` | 确定重心位置，测其到车身最前端的纵向距离，包含保险杠和外伸附件。 |
| `body_rear_extent_from_cg_m` | 测重心到最后端的纵向距离；前后距离之和应等于外廓总长。 |
| `body_width_m` | 测包含轮胎和附件的最大宽度，检查工作转角内的轮胎外伸。若使用重心居中的矩形且左右不对称，取左右最大外伸距离中较大者的两倍；不加避障裕量。 |
| `steering_gain_rad` | 选零位和左右多个请求，测稳定后的左右前轮角；递增、递减各测一遍。换算等效角后拟合 `delta = k*u+b`，得到 k；明显非线性时不强行用单一比例。 |
| `steering_offset_rad` | 分别从左右方向回到零请求，测等效转角，并与拟合截距 b 对照，检查回差。 |
| `steering_min_rad` | 在允许范围内逐步测到右转工作端点，记录最小等效角和对应请求，不顶住机械端点。 |
| `steering_max_rad` | 同样测左转工作端点，记录最大等效角和对应请求；不假定左右对称。 |
| `steering_rate_limit_rad_s` | 同步记录不同幅度、左右方向的请求和实际轮角；从角度—时间曲线估计持续变化率。只有可重复的斜率限制才能作为速率上限，不能用单次平均值或噪声峰值代替。 |
| `drive_min` | 确认 ESC 规则后，在低速下比较候选负向请求的减速及停车后行为，与控制组据此选定最小工作请求。 |
| `drive_max` | 在允许低速范围内比较正向请求对应的速度、加速与停止空间，按目标速度选定最大工作请求，不测试满油门。 |
| `drive_response_model` | 直行采集多个固定请求下的起步、加速、零请求滑行及可获得的稳态数据；按 MPC 纵向方程拟合响应，用独立运行验证速度预测。 |
| `braking_behavior` | 按已确认的 ESC 规则，低速验证前进→零、前进→制动、停止→后续请求；记录滑行、制动、倒车及是否需要回中立。 |
| `steering_delay_s` | 同步测请求变化到实际前轮角开始持续变化的时间差；不使用完成整个转向所需的时间。 |
| `drive_delay_s` | 分别记录静止起步和低速行驶时请求变化到运动响应的时间差；区分死区、静摩擦和轮速滤波，不能将表观延迟直接当成纯执行器延迟。 |

转向使用自行车模型的等效前轮角，不能直接取单侧轮角。在理想 Ackermann 几何、两轮同向且远离零角时，可用 `cot(delta) = [cot(delta_left)+cot(delta_right)]/2`；近零或几何不一致时需结合低速轨迹复核。近似无侧滑时，可用后轴中心转弯半径核对 `|delta| = atan(L/R_rear)`，左右方向确定符号。

## 数据与交付

每次测试记录：

- **工况**：运行编号、车号、配置版本、电池、载荷、地面及轮胎接地/支承状态。
- **指令与响应**：驱动/转向请求、轮速、偏航角速度、左右前轮角、时间及有效性；轮速无符号，运动方向另行记录。
- **测量依据**：几何尺寸、轴荷、量具精度、原始日志、角度视频或轨迹；注明视频与日志同步方式及误差，有来源时间戳则与接收时间分别保存。

每项参数交付数值或行为规则、单位、测量/拟合方法、适用范围、重复测量变动和独立复测结果；驱动限幅附选择依据，响应模型附方程与系数单位。

确认后填写 `vehicle_params.py`，未确认项保留 `None`。仅有滤波观测、无法分离的延迟需明确注明；不能用仿真假设或 0 补齐。
