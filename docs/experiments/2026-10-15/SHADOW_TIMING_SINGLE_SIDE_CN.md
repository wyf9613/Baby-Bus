# 影子 lattice 去除执行预测后的耗时与单侧道路验证

2026-10-15；本机离线，48 候选、基础轨迹 1 m，保持当前 YAML 参数。未运行 ROS 或实车。

## 修改

执行预测代价、逐候选 PID / 自行车推演、相关模型参数和执行预测话题已删除。候选排序只依赖几何回正、朝向、准备目标和弱平滑项。控制器增益 / 限幅不会影响分数。

## 配对耗时

对第 60–83 帧原始未遮挡输入交替测试修改前后版本，各 24 次：平均 **187.7 → 47.2 ms**，约 **3.98 倍**。
被删除的逐候选推演本身平均耗时 **139.0 ms**。before 仅是这次新影子原型的前一版本，不是旧 MVP2 lattice。

## 当前阶段分解

下表来自同一段 24 帧、每帧重复 2 次，共 48 次规划；配置 1 Hz。单位 ms，各阶段为所有候选的累计值。

| 阶段 | 平均 | p95 |
| --- | ---: | ---: |
| 输入整理 | 0.060 | 0.073 |
| Frenet 建立 | 0.043 | 0.050 |
| 采样参数 | 0.055 | 0.074 |
| 48 条候选生成 | 22.320 | 23.250 |
| 动态近段碰撞检查 | 13.014 | 18.142 |
| 几何评分 | 13.025 | 18.119 |
| 最优候选选择 | 0.012 | 0.015 |
| 结果组装 | 0.135 | 0.189 |
| 计时与循环开销 | 0.019 | 0.022 |
| 规划总耗时 | 48.683 | 56.286 |

注意：总耗时 p95 为 56.29 ms、最大 57.80 ms；各阶段 p95 不能相加。
原始进程首次任务往返 228.9 ms，包含进程启动。随后 7 个单侧任务平均往返 57.8 ms，其中算法 50.9 ms、子进程 JSON 编码 3.37 ms、父进程解码 2.30 ms。余下包含管道、调度等。
这些往返测量没有 ROS/DDS、控制调度或异步积压。规划总耗时不含感知；报告另列静态重建 + 规划的和，不能当成完整 policy 周期耗时。

## 单侧弯道场景

在感知输入前移除另一侧颜色；先由更早的一帧真实双侧观测学习路宽，然后不向当前重建或影子碰撞检查提供隐藏侧历史。短支持场景将单侧边界和参考支持同时截至 0.15 m，仍要求输出至少 1 m。

第二段为第 150–173 帧，录制时间 16.546–18.853 s，轮速 0.187–0.217 m/s。

| 场景 | 1 Hz 成功帧 | 1 Hz 平均 / p95 ms | 10 Hz 成功帧 | 10 Hz 平均 / p95 ms |
| --- | ---: | ---: | ---: | ---: |
| 原始数据（不保证始终双侧） | 24/24 | 42.71 / 44.51 | 24/24 | 33.70 / 35.93 |
| 仅左侧 | 24/24 | 39.50 / 41.75 | 24/24 | 32.42 / 34.29 |
| 仅右侧 | 24/24 | 40.49 / 43.72 | 24/24 | 34.02 / 35.67 |
| 左侧 0.15 m 支持 | 24/24 | 30.94 / 32.08 | 24/24 | 28.66 / 30.17 |
| 右侧 0.15 m 支持 | 24/24 | 32.57 / 35.37 | 24/24 | 28.72 / 30.28 |

第 60–83 帧：仅左侧 24/24 成功；仅右侧 3/24 有重建道路并成功，另外 21 帧是感知 insufficient_geometry，不输出边界或中心线，影子报告 NO_ROAD。不能把这些提前返回计入有效规划的速度优势；报告提供 planned_timing_ms。两段均保留完整结果，没有删去失败帧。

本机样本的计算时间低于 10 Hz 的 100 ms 预算；未证明 ROS 持续 10 Hz 调度或车载算力满足要求。单侧成功只表示在暂用车身尺寸、数值采样精度和已知支持边界下，近段未检测到碰撞，不表示未观测区域已安全或车辆实际跑通。
