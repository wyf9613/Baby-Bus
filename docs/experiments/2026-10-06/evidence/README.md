# Experiment evidence, 2026-10-06

This directory contains selected original result records, profiles, timing samples,
configuration snapshots and verification logs for the experiment report.
It excludes full workstation/car backups and transfer archives.

The car-only deployed configuration is an experiment snapshot, not the package
installation default. JSON distances are wheel-speed integrals, not independent
measurements of chassis displacement. Some result files are aliases/copies; see
the CSV index before counting independent runs.

Original source paths and process commands inside logs are historical records.
The complete telemetry and rollback files remain in the parent project workspace.
No live vehicle test is launched by these artifacts.
